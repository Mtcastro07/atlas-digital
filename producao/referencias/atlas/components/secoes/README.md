# `components/secoes/`

As seções do site e os blocos que elas reúnem. Todos são Server Components: o HTML chega pronto e legível sem script. O texto vem de `conteudo/site.ts`, salvo indicação. As seções são as do site de 28/08 (branch `branchCEO`); na fusão de 01/10, a `branchCto` acrescentou peças e materiais, marcados abaixo como "da branchCto". Desde 01/10, a pedido do usuário, o site tem uma página por assunto (`app/(atlas)/`), e as seções se distribuem assim: início (capa, as portas de `../paginas/portas.tsx`, chamada final); Para quem (para quem, vitrine); Planos (planos, escada, fundação); Orçamento (orçamento); O trabalho (trabalho); O Atlas (história, quem faz); Dúvidas (dúvidas, chamada final). O cabeçalho e o rodapé ficam no layout.

## Regras

- Seção nova: crie o arquivo com `Secao`, `Envelope` e `Abertura`; registre o id em `IdDaSecao` (`conteudo/site.ts`) e ponha o componente na página do assunto (`app/(atlas)/<página>/page.tsx`). Página nova: acrescente-a em `paginas` (`conteudo/site.ts`), com a abertura e a porta; o menu, as portas, o sitemap e a "próxima página" seguem a lista.
- Tons alternam para separar as seções; evite dois vizinhos iguais.
- Vínculo com cara de botão é `<a className={buttonVariants()}>`, não `<Button>`.
