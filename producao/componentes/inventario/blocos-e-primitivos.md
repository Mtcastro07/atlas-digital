# Frente 4 — blocos e seções, kits de interface e primitivos (12–13/10/2026)

> **Inventário do catálogo de componentes** (`../README.md`): a frente 4 da pesquisa de 12 e 13.10.2026, guardada como veio, com as citações. É registro datado: a licença se reconfere no ato de usar (`../README.md`, seção 3), e «frente N» remete ao arquivo desta pasta pela tabela de `../README.md`, seção 7.

**Pergunta:** quais blocos, kits e primitivos dão acabamento e interação premium e têm licença que permite usá-los em site feito e vendido para cliente, que recebe o repositório?

**Método.** A licença foi lida no arquivo do repositório, por clone raso sem checkout (`git clone --depth=1 --filter=blob:none --no-checkout`), com `git show HEAD:<arquivo>`. A data é a do último commit do `HEAD`, lida no mesmo clone. Versões e licença declarada vieram do registro npm. Sites sem repositório foram lidos por `curl` e extração de texto; páginas montadas só por script foram lidas pelo `WebFetch` ou pelo pacote JavaScript da própria página (caso do Flowbite). Os blocos e kits relevantes também foram clonados completos e lidos por um script estático (`ana.py`, no rascunho), que **não executa nada**. Ele conta:
- arquivos com `motion`, GSAP ou three;
- arquivos com tratamento de movimento reduzido ("reduz N");
- arquivos com animação ligada à rolagem (`useScroll`, `scrollYProgress`, `ScrollTrigger`, `animation-timeline`; "rolagem N");
- letreiros ("marquee N");
- os servidores das imagens embutidas.

As contagens são por arquivo, não por componente: são sinal, não prova. Nada foi instalado, executado nem compilado. No repositório do Atlas, só este arquivo foi escrito.

**Legenda do veredito** (primeira palavra da coluna):
- `LIBERADO`: MIT, Apache-2.0, BSD, ISC, MPL ou equivalente, lido no LICENSE do repositório.
- `CONDICIONAL`: Commons Clause, licença proprietária gratuita que permite expressamente cliente (cláusula citada), ou licença dupla com termos extras.
- `CNV`: condicional não verificado. O README ou o site diz "MIT" ou "free", mas não há LICENSE; o texto exato vai citado.
- `VETADO`: GPL, AGPL, LGPL, CC-BY-NC, só uso pessoal, pago, ou sem licença nenhuma.

Linha mista (parte livre, parte paga) vai com o veredito da parte livre, e a fronteira fica escrita na mesma célula.

## 0. Achados que mudam o kit (resumo)

1. **O Tailwind Plus está fechado.** A Shopify comprou a Tailwind Labs em 09/09/2026, e as vendas a clientes novos pararam no mesmo dia ([CMSWire](https://www.cmswire.com/digital-experience/shopify-acquires-tailwind-labs-to-secure-css-framework/); [devtoolpicks](https://devtoolpicks.com/blog/best-tailwind-plus-alternatives-indie-hackers-2026)). Conferido por `curl` em 12/10/2026: `tailwindcss.com/plus`, `/plus/license`, `/plus/ui-blocks` e `/plus/templates` respondem 302 para `/plus/login`. Não existe "parte gratuita" do Tailwind Plus. O Headless UI (MIT) é da mesma casa, e o último commit dele é de 13/04/2026.
2. **O Base UI 1.9.0 (09/10/2026, MIT) já cobre o que se buscava fora dele.** Ele exporta `./drawer`, `./toast`, `./otp-field`, `./combobox`, `./autocomplete`, `./preview-card` e `./navigation-menu` (npm). Isso substitui, sem dependência nova, o **Vaul** (README: "This repo is unmaintained"; último npm em 14/12/2024), o **Sonner**, o **input-otp** e boa parte do **cmdk**. A documentação do shadcn já manda a gaveta para o Base UI (`content/docs/components/aria/drawer.mdx`: "The drawer component uses Base UI").
3. **O shadcn tem três bases:** `registry/bases/{radix,base,aria}`, e a `aria` usa o React Aria Components. O **Tailark** traz as bases `base` e `radix` lado a lado (`registry/bases/base/{mist,veil,dusk}`). O mesmo vale para o Dice UI e o Shadcn Space. O kit, em `base-nova`, pode copiar blocos já no Base UI.
4. **Divergências de licença** (vale o LICENSE do repositório):
   - **HeroUI:** LICENSE Apache-2.0, npm "MIT".
   - **Beste UI:** LICENSE MIT, mas a página `/license` traz uma "Beste UI License" restritiva.
   - **PrebuiltUI:** LICENSE MIT, mas o site tem uma "Free License" com restrições.
   - **Flowbite:** código MIT, mas a documentação, onde moram os trechos copiáveis, é "CC BY 3.0".
   - **Xtend UI:** documentação em CC BY 4.0.
   - **Wind UI:** a página de licença traz MIT e CC BY-SA 4.0 sem dizer a que parte cada uma vale.
5. **A entrega do repositório ao cliente choca com licenças pagas comuns:**
   - **Untitled UI PRO:** "as long as source files (JSX, Tailwind, Figma files etc.) are not exposed".
   - **shadcncraft:** o produto final "does not allow the end user to … download, or reuse the original shadcncraft source files".
   - **Wensity:** "Keep proprietary component source private".

   Mesmo que se pagasse, o modelo do Atlas (o cliente fica com o código) quebraria a licença.
6. **As armadilhas de "grátis" que não são:**
   - **Once UI:** Magic Portfolio e Magic Docs são **CC BY-NC 4.0**, e o Magic Portfolio aparece como modelo na galeria da Vercel.
   - **Cruip:** os modelos são **GPL**, e o README acrescenta "don't republish, redistribute, or resell".
   - **Flx (ui.flexnative):** **AGPL-3.0**.
   - **tints.dev:** **CC BY-NC 4.0**.
   - **lightGallery:** "GPL-3.0-only OR LicenseRef-Commercial".
   - **Fancybox:** licença própria paga.
   - **a11y-starter-kit:** o awesome diz "free", mas o LICENSE é de planos pagos.
7. **As imagens embutidas nos blocos não podem ir ao site do cliente:**
   - **Pinterest (`i.pinimg.com`)** no Sera UI e no Ruixen UI: imagens de terceiros.
   - **Freepik (`img.freepik.com`)** no MVPBlocks e no Tailus, e **Flaticon** no Pines e no Tailus: atribuição obrigatória no plano gratuito.
   - **Themefisher:** "The images are only for demonstration purposes … we don't have permission to share those images".
   - **WickedBlocks:** imagens do Dribbble, do Twitter e do Gumroad.
   - **ChatDeck:** lê imagens do demo pago do Startup Template da Magic UI.
   - **Retratos fictícios** de randomuser.me, pravatar, uifaces e dicebear.

   As de `images.unsplash.com` são de licença livre, mas são pedido externo, vedado pelo kit. A regra é uma só: **toda imagem de bloco sai e entra a fotografia do negócio.**
8. **Vetos do kit encontrados no código:**
   - O **uiable** declara `lenis` (rolagem com inércia, vetada pela ata v3.0) e `three`.
   - Velora, Ruixen, UI Layouts, MVPBlocks, Beste, Cubby, Intent UI e Appica têm componentes **ligados à rolagem**: só no Completo, e só por `animation-timeline` dentro de `@supports`, nunca com inércia.
   - O letreiro (K4) aparece em quase todos os catálogos de seção (Shadcn UI Blocks 71 arquivos, ReUI 38, Shadcn Space 38, UI Layouts 31, Dice UI 28).
